Dialogue Locator

Find the first frame where a spoken line occurs in a video

API docs

1 Input

YouTube, ok.ru and any other yt-dlp supported site, or a path to a file on this machine.

Case and punctuation don't matter. Two or more words.

2 Pipeline

  1. Validate input
  2. Fetch audio
  3. Extract audio
  4. Transcribe & match
  5. Verify with large model
  6. Download clip
  7. Extract frame
  8. Detect face
  9. Detect mouth movement
